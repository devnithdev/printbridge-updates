How to install

  1. Download PrintBridgeSetup.exe with the button above.Windows 10 or 11, 64-bit.
  2. Open it. If a blue “Windows protected your PC” box appears, click More info, then Run anyway, and allow the changes.
  3. Choose what this computer does: the main computer, a computer with a printer, or one that only prints. Give it a name like “Front desk”.
  4. On the main computer, tick Make this the only main computer and Give this computer a fixed address (recommended).
  5. Press Finish. On the main computer, the sign for the wall opens: print it and put it up.
  1. Download the installer with the button above.Apple Silicon and Intel Macs.
  2. Double-click PrintBridge.pkg. If macOS says it can’t be opened, click Done, then open System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. Follow the installer and enter your Mac password. A setup page opens in your browser.
  4. Choose what this Mac does and give it a name. On the main computer, tick Make this the only main computer and Give this computer a fixed address.
  5. Press Set up PrintBridge and keep the page open until it says All set.

Order: the main computer first, then the computers with printers, then the ones that only print. Each finds the main computer by itself.

Questions

What does PrintBridge do?

It lets everyone in the office print to any office printer from their own phone or computer. One computer runs a small printing page; people open it, choose a file and a printer, and press Print. Computers with PrintBridge can also print straight from Word, Excel and other programs.

Do people need an app or an account?

No. On a phone, people scan the sign on the wall (or type its address) and print from the browser. Only the computers in the office get PrintBridge installed.

Which computer should be the main computer?

One that stays on during office hours, ideally connected by cable. It runs the printing page for everyone. Set up only one; ticking “Make this the only main computer” makes any other one switch over to it by itself.

What happens after a power cut?

PrintBridge starts again on its own when the computers are switched on, with nobody signed in, and the computers find each other again. Jobs that were waiting are sent again; a page that was cut off mid-print is not printed twice.

How do I update it?

You don’t need to. From version 4.1.3 on, each computer installs new versions by itself, when nothing is printing, and keeps all its settings. To check straight away, choose “Update PrintBridge now” in the Start menu (Windows) or the PrintBridge folder in Applications (Mac).

Is it safe?

The printing page only works inside the office network. Updates are only installed if they carry PrintBridge’s own signature, and each installer is checked against it before it runs, so a changed or fake file is never installed.

Can it print Word, Excel and photos?

PDFs always print. For Word, Excel, PowerPoint files and photos, tick “Also install LibreOffice” (free) when setting up the main computer.

How do I remove it?

Windows: Settings → Apps → PrintBridge → Uninstall. Mac: Applications → PrintBridge → Uninstall PrintBridge. It removes everything it added, including the “PrintBridge” printer, and puts the power settings back.

Something isn’t working. What do I check?

Open “Check PrintBridge” on that computer (Start menu, or the PrintBridge folder in Applications). It says in plain words what is wrong and how to fix it.
